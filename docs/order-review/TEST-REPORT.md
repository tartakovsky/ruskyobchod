## Последние изменения интерфейса

- Дата передачи и подтверждение клиенту находятся в основном блоке.
- «Утвердить» заблокирована без даты курьеру; проверены пустая, прошедшая и допустимая дата, а также очистка поля.
- Метабокс `rusky-shipping-notice-email` удалён для новых заказов; старый отправитель отказывает для заказов новой схемы. Packeta/GLS сохраняются.
- Фактический вес вводится без «Изменить». Показан сохранённый при покупке диапазон на единицу и общий диапазон; вес вне диапазона отклоняется.
- В причинах корректировки оставлены отсутствие товара и изменения по просьбе клиента.
- Четыре варианта письма RU/SK выбираются по составу и весу. Одна таблица состава, без повторения исходной; описание изменений формируется автоматически.
- Русский выбирается только при `_gastronom_lang=ru`; иначе словацкий.
- Дополнительные проверки Review flow и Four email variants также прошли; их внутренние assertions не включены в счётчик 246.

## Подготовка установки 14.09.2026: вес посылки

Удалены требование физической массы обычного SKU и автоматический расчёт/перезапись веса посылки в новом блоке. Packeta сохраняет собственный рассчитанный, ручной или отсутствующий вес для штатной проверки. Уточнение веса весовых товаров, индивидуальные диапазоны, цена, остаток кг и кассовые количества сохранены.

Тесты теперь подтверждают обычные заказы с пустой массой товара и отдельно проверяют сохранение рассчитанного/ручного/отсутствующего веса Packeta, включая значение меньше суммы масс товаров. Полная проверка запущена также на копии WooCommerce 10.7.0 с рабочего сервера (дополнительно к 10.6.2), в posts и HPOS. Staging PHP 8.2 / WooCommerce 11.0.1: четыре сценария, 75 проверок, полный откат, 0 внешних HTTP/почтовых обращений. См. staging-check/result-final.json.

GLS на рабочем сервере отличается от исходного Git-файла только завершающим переводом строки; манифест учитывает фактический SHA-256, функциональные изменения перевозчика не перетираются. Рабочий домен и изменения входа магазина включены из текущей main и не откатываются.
