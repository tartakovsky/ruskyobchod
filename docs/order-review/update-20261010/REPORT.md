Новый процесс: изменить состав → предпросмотр → отправить изменения → клиент
открывает кнопку в письме и явно подтверждает на странице → администратор
утверждает заказ. Запасное согласование по письму/телефону записывает время само.
Возвращение к карточке обновляет статус без таймеров; есть ручная кнопка обновления.
Старые отправленные письма поддерживаются; повторной отправки при обновлении нет.

Письмо указывает товары, исходное/предложенное/недостающее количество, точную
стоимость, извинение при нехватке и варианты связи. Учитываются части заказа,
килограммы и дубли одного товара. Язык админки и язык письма независимы.
Заголовок CPT исправляется в представлении редактора, исходный заказ не меняется.
Русская ошибка условий в словацком checkout исправлена в существующем серверном
языковом модуле. Новых глобальных переводчиков, таймеров и DOM-наблюдателей нет.

согласуют; POST не выполняет кассу, оплату, склад или доставку. Повтор безопасен,
изменение состава/получателя делает старую ссылку недействительной. Страница
private/no-store/no-referrer/noindex, без внешних ресурсов и скриптов.
